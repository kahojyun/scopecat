# Calibration Fit Recovery Interaction Recording Candidate

This package is an implementation candidate, not accepted Scopecat
architecture.

It records explicit user interaction events for calibration fit recovery and
projects their result through the existing fit recovery workflow and review
state candidates. The candidate helps validate the continuity between a local
review interaction and the already validated recovery read models.

The package does not implement a GUI, execute fits, score fit quality, choose
ROI or initial guesses, remeasure, apply parameter writes, provide a replay
harness, implement a dataset registry, emit a portable/public dataset package,
or control hardware.
