# Handoff Package GUI View-State Candidate

This package is an implementation candidate, not accepted Scopecat
architecture, a live GUI framework, final GUI contract, plotting library,
stable SDK, dataframe API, importer, storage model, or package format.

It tests whether existing read-only handoff package projections can be shaped
into one local GUI-ready state:

- consume the preview-aware consumption receipt for first-surface selection;
- consume the plot-first visual-review model for visual summaries, axis facts,
  table drilldown facts, linked context, and findings;
- expose measurement-list navigation and a default selected measurement;
- expose a primary surface of `plot`, `table_drilldown`, or
  `review_findings`;
- keep renderer, dataframe, import, storage, integrity, archive, schema
  inference, and shared measurement-model behavior out of scope.

The summary is a local `review_summary`. It is not a portable/export artifact,
public report, package member, UI implementation, rendered plot, dataframe
adapter, package import record, or final SDK/API surface.
