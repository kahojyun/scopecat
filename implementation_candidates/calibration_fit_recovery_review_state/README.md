# Calibration Fit Recovery Review State Candidate

This package is an implementation candidate, not accepted Scopecat
architecture.

It projects the calibration fit recovery workflow candidate into a review
surface state that a future notebook panel or GUI could consume. The state
contains incident cards, primary actions, dataset-selection controls,
continuation banner state, and missing-context findings.

The package does not implement a GUI, execute fits, score fit quality, choose
ROI or initial guesses, remeasure, apply parameter writes, provide a replay
harness, implement a dataset registry, or control hardware.
