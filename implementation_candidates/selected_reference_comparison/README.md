# Selected Reference Comparison Implementation Candidate

This package is an implementation candidate, not accepted Scopecat
architecture.

It holds a production-shaped experiment for selected-reference comparison:

- compare a current measurement against an explicitly selected reference;
- treat ordinary measurement marks as selection context;
- report objective context findings for declared preview metadata, named input
  snapshots, selected artifacts, declared facts, and recorded code context;
- keep the builders side-effect free;
- avoid raw-data comparison, fit-quality comparison, user judgment, setup
  truth, automatic cause attribution, Git inspection, source diff, workspace
  restore, environment readiness, code import, code execution, shared
  run-context framework, or GUI behavior.

The package exists to test whether selected-reference review output can become
implementation-shaped while preserving the fixture boundary.
