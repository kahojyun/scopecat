# Running Measurement Inspection Candidate

This package is an implementation candidate, not accepted Scopecat
architecture.

The candidate builds a side-effect-free summary for inspecting already-recorded
data from a still-running measurement. It uses explicit fixture facts only. It
does not open source data, poll live services, render plots, save analysis
results, control hardware, mutate scan plans, or define a final lifecycle,
reader, monitor, callback, GUI, plotting, storage, import, or export contract.
