# Calibration Continuation Route Shape

Tiny implementation candidate for a static calibration continuation route shape.

It consumes an explicit route input-contract summary and fixture-declared route
card facts, then produces an internal validation summary for a future product
shape. It does not render a GUI, execute calibration or fitting code, read
referenced payloads, choose ROI or initial guesses, replay cases, create dataset
registry entries, write parameters, or control hardware.
