# Scopecat

<p align="center"><img src="assets/branding/app-icon.svg" alt="Scopecat app icon" width="160"></p>

Scopecat watches your lab runs, catches the traces, and remembers what changed.

Scopecat is a local experiment memory system for scientific measurement workflows. It starts with simple measurement history: write data from ordinary lab scripts, inspect traces while work is running, and reopen durable records later by stable IDs.

## Early Direction

- Record lab runs, traces, datasets, notes, and lightweight context.
- Keep first adoption friendly to ordinary Python scripts and notebooks.
- Preserve room for parameter memory, code provenance, scan planning, and reviewed automation later.

## Status

New project workspace. Product and architecture details are still being designed.
