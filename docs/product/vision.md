## Vision

Scopecat should make existing scientific measurement work easier to record,
inspect, select, hand off, compare, recover, and continue without forcing users
to replace working lab systems first.

Its first product value is brownfield-friendly quality-of-life improvement:
capture and review useful measurement context around existing files, tools,
code, runs, and handoff paths.

Deeper ownership of storage, execution, environment restoration, scheduling, or
hardware authority should be earned only when a target journey proves that
lighter recording, review, adapter, or handoff support is not enough.

## Posture

Scopecat should help before it replaces. Early adoption should preserve
working lab systems and add reviewable evidence, explicit context, safer
handoff, and better continuity around them.

Useful product work should therefore prefer:

- review before import, mutation, or authority transfer;
- explicit references over inferred ownership of messy external systems;
- workflow evidence over discovery-fixture shape;
- entrypoint-driven modernization over broad platform replacement;
- narrow promoted capabilities over shared models invented too early.

Use [`success-metrics.md`](success-metrics.md) to judge whether a capability is
actually improving this vision.
