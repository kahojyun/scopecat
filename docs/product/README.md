# Product

## Status

Product documentation navigation.

## Purpose

Product docs own Scopecat's product strategy, adoption model, and capability
map. They explain what the product is trying to become and how users can adopt
it around existing lab systems.

Use engineering docs for delivery maturity, implementation ownership,
prototype boundaries, tests, fixtures, and live API details. Use discovery docs
for evidence, problem framing, validation plans/results, and historical route
grouping.
