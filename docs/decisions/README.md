# Decisions

## Status

Project-wide ADR directory.

## Purpose

Use this directory for durable cross-project architecture decisions.
Subsystem-specific decisions belong under `docs/subsystems/<name>/decisions/`.

## Naming

Use:

```text
ADR-0001-short-title.md
```

Keep ADRs focused on accepted or explicitly rejected decisions. Exploratory
notes belong in `research/` or the relevant subsystem directory.
