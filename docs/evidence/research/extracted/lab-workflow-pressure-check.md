## Retained Pressure Lenses

Pre-run code and context:

- copied experiment-code folders, ambiguous entrypoints, local paths, helper
  packages, and dependency readiness;
- selected code scope, selected references, and restore or migrate questions.

Setup and bring-up:

- wiring sheets, registry files, driver initialization, diagnostics, local
  aliases, and physical facts that software cannot prove alone;
- recipient-aware sharing boundaries for internal support versus exported docs.

Calibration and parameters:

- direct parameter writes, snapshots, registry drift, bad states, and working
  branches;
- fit quality, review pauses, retry/refit decisions, continuation, and
  downstream blocking.

Measurement-time work:

- selected run ranges, scan semantics, generated protocols, run families, and
  partial recorded data;
- read/monitor workflows that consume explicit records without taking over
  hardware control.

Analysis handoff:

- moving selected high-value runs from a control computer to analysis context;
- derived arrays, notebooks, corrections, exclusions, figures, spreadsheets,
  decks, reports, and missing-context warnings.
