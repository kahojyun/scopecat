# Getting started

The shortest path into Scopecat is a hardware-free project created by the CLI.
It uses the same daemon, project discovery, configuration history, and GUI that
a real lab uses later.

- [Source preview quickstart](quickstart.md) closes the complete first-run loop.
- [Project layout](../reference/project-layout.md) explains the files generated
  by `scopecat init`.
- [Reference lab tutorial](../tutorials/reference-lab.md) provides the next,
  richer workflow after the starter project.

Scopecat is currently documented from a source checkout. A distribution install
command will replace the source preparation section once release artifacts are
published.
