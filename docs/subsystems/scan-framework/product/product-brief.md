# Scan Framework Product Brief

## Status

Draft.

## User Promise

Users can define scan intent, preview scan points, render desired instrument
state, and debug plan shape before touching live hardware.

## Early Scope

- grid scan plans
- scan variables
- fixed experiment-local parameters
- desired-state rendering
- preview and dry-run output
- metadata suitable for Measurement History

## Non-Goals

- durable parameter memory
- live instrument lease policy
- remote execution coordinator
- full workflow engine
