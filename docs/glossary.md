# Glossary

## Status

Provisional terminology helper.

## Terms

**Measurement History**
System for recording experiment runs, datasets, lineage, and historical facts.

**Scan Framework**
Framework for scan variables, fixed parameters, desired-state rendering,
preview, and scan-point execution semantics.

**Parameter Memory**
System for durable parameters, calibration history, immutable snapshots, and
reviewable parameter updates.

**Code Asset Registry**
Registry for reusable code assets, source references, versions, hashes,
entrypoints, and compatibility metadata.

**Instrument Runtime**
System for live instrument services, health, leases, conflict prevention, and
actual state snapshots.

**Managed Code Runner**
System for controlled execution, logs, artifacts, environment snapshots,
status, and cancellation.

**ExperimentPackage**
Immutable package representing locally designed and previewed experiment intent
for remote validation and execution.

**Desired Instrument State**
The target state rendered by the Scan Framework.

**Actual Instrument State**
The state acknowledged or read back by Instrument Runtime.
