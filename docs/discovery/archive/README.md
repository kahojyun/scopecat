# Discovery Archive

## Status

Historical discovery coordination notes, retired route synthesis, and frozen
inventories.

## Purpose

This directory preserves discovery evidence that should remain linkable but
should not be read as current implementation ownership or active route
sequencing. Start from [`../README.md`](../README.md) for current discovery
navigation and from
[`../../engineering/implementation-register.md`](../../engineering/implementation-register.md)
for active engineering ownership.

Do not update archived notes to mirror current APIs. Edit them only to fix
broken links, remove unsafe content, or clarify that a newer owner has replaced
the old discovery path.
