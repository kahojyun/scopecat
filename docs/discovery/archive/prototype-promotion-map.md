# Prototype Promotion Map

## Status

Archived coordination index.

Decision status: retired.

This document preserves a historical route-by-route promotion status for
Scopecat discovery and engineering-prototype work. Do not use it to find
current live owners, coordinate new branches, broaden a route's scope, override
an engineering boundary, infer final product sequencing, or decide whether a
user workflow is validated.

Workflow validation is owned by
[`../../engineering/workflow-validation-map.md`](../../engineering/workflow-validation-map.md).
Implementation ownership is owned by
[`../../engineering/implementation-register.md`](../../engineering/implementation-register.md).

Do not update this matrix to mirror current implementation APIs. Edit it only
to fix broken links, safety issues, or historical supersession notes.

## Status Vocabulary

| Status | Meaning |
| --- | --- |
| Promoted engineering prototype | A scoped engineering boundary is accepted in `src/scopecat/` and an architecture note or module README owns the live behavior. |
| Historical discovery evidence | Discovery or candidate work remains useful evidence but is superseded, retired, or no longer the active implementation path. |
| Implementation candidate only | Validated candidate behavior exists, but no accepted live implementation boundary owns it yet. |
| Next-promotion-ready | Evidence appears sufficient for a narrow engineering promotion once an implementation branch chooses that exact boundary. |
| Paused or blocked | Broad expansion should stop, or promotion needs a missing authority decision, external contract, or product boundary. |
| Superseded | A former candidate or discovery path has been replaced by an accepted owner or newer decision; keep it as evidence, not as the implementation path. |

## Archive Edit Rule

When a branch changes current promotion status:

- update the active workflow map, product capability map, implementation
  register, boundary note, or module README instead of this archived matrix;
- preserve this file as historical evidence;
- edit this file only for broken links, safety issues, or explicit
  supersession clarification.
